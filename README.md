# The Answer Book
A Answer Book Website where you ask a question and get an answer from The Answer Book and ai will explain you what does it means

https://dreamtraveller1314.github.io/API-Website/

## How I Built It

I used HTML and CSS to create the website layout and design, while JavaScript handles the API requests. I connected the Answer Book API to get random answers and Groq AI API to generate explanations based on the user's question and answer.

## What I Learned

Through this project, I learned how to connect APIs using JavaScript, handle JSON responses, and integrate AI into a website. I also gained more experience in frontend design and making a website more interactive.
